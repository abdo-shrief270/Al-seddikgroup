الوضع الحالي وفلسفة التسعير

الموقع الحالي صفحة واحدة ثابتة (HTML) — كل المحتوى من نصوص وصور ومشاريع وبيانات تواصل مكتوب داخل الكود، وأي تعديل بسيط يحتاج مبرمجاً. الهدف نقل الموقع إلى نظام تتحكم فيه الإدارة بنفسها.

١

كيف تم تخفيض السعر؟ بتغيير نطاق العمل وليس بتقليل الجودة

  • الباقتان الأولى والثانية: نحتفظ بتصميم الموقع الحالي كما هو ونحوّله إلى قوالب ديناميكية على Laravel مباشرة — بدون إعادة بناء الواجهة بـ Vue. هذا يوفّر أكثر من نصف وقت العمل، وينعكس مباشرة على السعر.
  • من الباقة الثالثة فأعلى: إعادة بناء كاملة بـ Vue.js / Nuxt مع API منفصل — وهي الخطوة التي تحتاج وقت عمل أكبر.
  • في كل الحالات: قاعدة البيانات وبنية النظام واحدة منذ الباقة الأولى، لذلك الترقية لاحقاً لا تعني إعادة بناء — تُدفع الفروق فقط.
٢

مشترك في جميع الباقات

  • الحفاظ على شكل الموقع وتصميمه الحالي دون أي تغيير بصري.
  • لوحة تحكم عربية تعمل على الكمبيوتر والموبايل، بنظام مستخدمين وصلاحيات.
  • رفع الموقع وتشغيله + نقل المحتوى الحالي + نسخة احتياطية.
  • تسليم كود المشروع كاملاً + شرح استخدام للفريق.
الباقات متتابعة وليست منفصلة: كل باقة تشمل كل ما في الباقة التي تسبقها. يمكن البدء بأي باقة والترقية لاحقاً بدفع الفرق فقط، كما هو موضح في صفحة المقارنة.

١. تحكم في الأساسيات

أقل تكلفة ممكنة للتخلص من الاعتماد على المبرمج في التعديلات اليومية. الموقع بشكله الحالي، لكن بياناته الأساسية أصبحت تُدار من لوحة تحكم.

✦

ما تتحكم فيه الإدارة

  • الشعار وأيقونة المتصفح.
  • ألوان الموقع (اللون الذهبي والأسود والخلفيات) عبر منتقي ألوان بسيط.
  • بيانات التواصل: رقم الهاتف، الواتساب، البريد الإلكتروني، العنوان.
  • روابط السوشيال ميديا (فيسبوك، إنستجرام...).
  • نصوص الأقسام الرئيسية: القسم الرئيسي (Hero)، ونبذة «من نحن»، وصورهما.
✦

طلبات العملاء

  • نموذج الحجز يُحفظ في قاعدة بيانات الشركة بدلاً من الخدمة الخارجية الحالية.
  • صفحة لعرض الطلبات مع إمكانية التصدير إلى Excel.
  • إشعار بالبريد الإلكتروني عند وصول أي طلب جديد.
  • حماية أساسية من الرسائل المزعجة.
حدود هذه الباقة بوضوح: المشاريع والخدمات وآراء العملاء تبقى ثابتة كما هي حالياً (تعديلها يحتاج مبرمجاً)، ولا توجد إدارة SEO ولا مكتبة وسائط ولا نظام صلاحيات متعدد المستويات. إن كان تعديل المشاريع أولوية، فالباقة الثانية هي البداية المناسبة.

٢. موقع ديناميكي بالكامل

كل ما في الباقة الأولى + التحكم في كل محتوى الموقع دون استثناء، وعلى رأسه المشاريع ومعارض صورها. هذه هي الباقة التي تجعل الموقع مستقلاً تماماً عن المبرمج.

✦

إدارة المحتوى الكامل

  • المشاريع: إضافة وتعديل وحذف مشروع كامل — الاسم، التصنيف، الوصف، صورة الغلاف، ومعرض الصور الداخلي، مع الترتيب وتحديد المشاريع المميزة.
  • الخدمات: إضافة وتعديل وإعادة ترتيب الخدمات.
  • آراء العملاء: إضافة وإخفاء وإظهار.
  • مراحل العمل والقوائم العلوية والسفلية.
  • مكتبة وسائط مع ضغط الصور وتحويلها تلقائياً لصيغة WebP السريعة.
✦

تحسين الظهور في جوجل

  • إدارة عنوان ووصف الصفحة وصورة المشاركة (SEO).
  • خريطة موقع تلقائية تتحدث مع كل مشروع جديد.
  • بيانات Google المنظمة للشركة والمشاريع.
✦

الطلبات والإدارة

  • متابعة الطلبات بحالات (جديد / تم التواصل / تم التعاقد / مرفوض) مع الملاحظات.
  • إشعار فوري على الواتساب بكل طلب جديد بالإضافة للبريد.
  • حماية متقدمة (reCAPTCHA + تحديد المعدل).
  • صلاحيات متعددة (مدير / محرر محتوى) مع سجل يوضح من عدّل ماذا ومتى.
  • نسخ احتياطي يومي تلقائي لقاعدة البيانات والصور.

٣. إعادة بناء بـ Vue.js + API

كل ما في الباقة الثانية، مع إعادة بناء الموقع بالكامل بتقنية Vue.js / Nuxt وواجهة API منفصلة على Laravel — وهي البنية المطلوبة لأي توسع مستقبلي (تطبيق موبايل، لغة ثانية، أنظمة إدارية).

✦

البنية التقنية

  • Laravel 12 API منفصل بالكامل + Nuxt 3 للموقع بتقنية العرض من الخادم (SSR) للحفاظ على ترتيب الموقع في جوجل.
  • لوحة تحكم Vue 3 حديثة وسريعة بواجهة عربية كاملة.
  • تخزين مؤقت بـ Redis وتحسين سرعة التحميل.
  • تجهيز بيئة التشغيل وتأمينها بالكامل مع شهادة SSL.
✦

إضافات هذه الباقة

  • بنية جاهزة للغة الإنجليزية — إضافتها لاحقاً لا تحتاج إعادة بناء.
  • صفحة منفصلة لكل مشروع برابط خاص قابل للمشاركة والأرشفة في جوجل.
  • إمكانية إضافة مدونة / أخبار لتحسين الظهور في البحث.
  • لوحة إحصائيات بسيطة (عدد الطلبات، أكثر المشاريع مشاهدة).
  • تحسين السرعة للوصول لتقييم مرتفع في Google PageSpeed.
  • الأساس الجاهز لإضافة أنظمة الموارد البشرية والمحاسبة لاحقاً.

٤. نظام إدارة الموظفين والمشاريع

كل ما في الباقة الثالثة + نظام داخلي لإدارة الموظفين والحضور والرواتب والمشاريع داخل نفس لوحة التحكم.

✦

شؤون الموظفين

  • الإدارات والمسميات الوظيفية.
  • ملف كامل لكل موظف: البيانات، الرقم القومي، العقد ومدته، مكونات الراتب.
  • أرشيف مستندات مع تنبيه قبل انتهاء العقود.
  • بوابة الموظف: يدخل ليرى ملفه وقسائم راتبه ويقدّم طلب إجازة.
✦

الحضور والإجازات

  • تعريف الورديات وجداول العمل.
  • تسجيل الحضور من الموبايل مع تحديد الموقع الجغرافي للمواقع الإنشائية.
  • حساب آلي للتأخير وساعات الإضافي.
  • كشف حضور شهري مع تعديل يدوي بسجل موافقات.
  • الإجازات والأرصدة والعطلات الرسمية ودورة الموافقة.
✦

الرواتب وقسائم الراتب

  • هيكل رواتب مرن (أساسي + بدلات + خصومات).
  • حساب التأمينات وضريبة الدخل وفق الشرائح المصرية بقواعد قابلة للتحديث.
  • ترحيل آلي للإضافي والخصومات من الحضور.
  • مسيّر رواتب شهري + قسيمة راتب PDF بالعربية + ملف تحويل بنكي.
✦

إدارة المشاريع

  • ملف مشروع داخلي: العميل، الموقع، المراحل، نسبة الإنجاز.
  • مهام بنظام لوحات وتوزيعها على الموظفين.
  • تقرير يومي للموقع: الإنجاز، العمالة، المعدات، وصور.
  • ربط ساعات العمل بالمشاريع + تقرير التكلفة البشرية لكل مشروع.

٥. إضافة النظام المالي والمحاسبي

كل ما في الباقة الرابعة + نظام مالي عملي مصمم لشركات المقاولات: فواتير مستخلصات ومحتجزات، مستخلصات مقاولي الباطن، وتكلفة وربحية فعلية لكل مشروع.

✦

العملاء والفواتير والتحصيل

  • ملفات العملاء + عروض الأسعار وتحويلها إلى عقود.
  • فواتير المستخلصات (الفوترة بنسبة الإنجاز) — الأهم في أعمال المقاولات.
  • معالجة المبالغ المحتجزة وخصم الدفعة المقدمة تلقائياً.
  • ضريبة القيمة المضافة ١٤٪ وضريبة الخصم والإضافة.
  • إيصالات التحصيل + أعمار الديون وكشف حساب لكل عميل.
✦

الموردون والمصروفات

  • ملفات الموردين ومقاولي الباطن.
  • أوامر الشراء وفواتير الموردين وسداداتها.
  • مستخلصات مقاولي الباطن ومتابعة مستحقاتهم.
  • المصروفات وعُهد النثرية والحسابات البنكية والخزينة.
✦

الربط والتقارير

  • ربحية كل مشروع: الموازنة مقابل المنصرف الفعلي (عمالة + مواد + مقاولي باطن).
  • ترحيل تكلفة الرواتب على المشاريع تلقائياً.
  • تقارير الإيرادات والمصروفات والتدفق النقدي.
  • تقرير مستحقات العملاء ومستحقات الموردين.
  • صلاحيات مالية دقيقة وسجل تدقيق لكل عملية مالية (لا حذف نهائياً).
توضيح مهم: هذه الباقة نظام مالي تشغيلي يغطي الفواتير والمستخلصات والتحصيل والتكلفة والربحية. أما دليل الحسابات الشجري والقيد المزدوج والقوائم المالية الرسمية (ميزان المراجعة والمركز المالي) فتُضاف بعرض منفصل تقديرياً ٣٥٬٠٠٠ ج.م، والربط بمنظومة الفاتورة الإلكترونية (ETA) بعرض منفصل تقديرياً ٤٠٬٠٠٠ ج.م.

جدول الدفعات

  • في الباقتين الرابعة والخامسة يمكن تقسيم الدفعات على مراحل الوحدات بالاتفاق.

تكاليف سنوية (على الشركة ولا تُدفع لنا)

  • اسم النطاق والشهادة الأمنية: ٨٠٠ – ١٬٥٠٠ ج.م سنوياً.
  • خدمة إشعارات الواتساب (اختيارية حسب الاستخدام).
✦

الصيانة بعد فترة الدعم المجاني

  • عقد شهري اختياري يشمل المتابعة والنسخ الاحتياطي والتحديثات الأمنية والتعديلات البسيطة.
  • تُحدَّد قيمته حسب الباقة ونطاق المتابعة المطلوب، بالاتفاق عند انتهاء فترة الدعم المجاني.
✦

غير مشمول

  • إعادة تصميم هوية الموقع أو الشعار (الالتزام بالتصميم الحالي).
  • كتابة المحتوى والتصوير الفوتوغرافي للمشاريع.
  • ترجمة المحتوى للإنجليزية (البنية جاهزة من الباقة الثالثة).
  • القيد المزدوج والقوائم المالية الرسمية (+٣٥٬٠٠٠ ج.م).
  • الفاتورة الإلكترونية ETA (+٤٠٬٠٠٠ ج.م).
  • تطبيق موبايل أصلي (النظام يعمل من متصفح الموبايل كتطبيق PWA).
  • أجهزة البصمة أو الربط بجهاز لا يدعم التصدير أو الـ API.
مسؤوليات العميل: توفير المحتوى والصور وبيانات الموظفين والأرصدة الافتتاحية في مواعيدها، وتخصيص شخص مسؤول للمراجعة والاعتماد في كل مرحلة. التأخير في هذه النقاط يؤدي إلى تأخير مماثل في تسليم المشروع.
